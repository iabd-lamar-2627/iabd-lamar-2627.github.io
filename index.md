# Git y GitHub

Todo el código que escribas en el curso vivirá en un repositorio Git. Este mini-curso te enseña lo mínimo imprescindible para empezar y no perder trabajo.

## Qué tendrás al terminar

- Git instalado y configurado con tu nombre.
- Una cuenta de GitHub y la sesión iniciada desde tu ordenador.
- Un repositorio tuyo con tu **primer commit** subido a GitHub.

## Git y GitHub no son lo mismo

| | Qué es | Dónde vive |
|---|---|---|
| **Git** | El programa que guarda el historial de tus cambios | En tu ordenador |
| **GitHub** | Un servicio web donde se guarda una copia de tus repositorios | En internet |

Git funciona sin GitHub. GitHub sirve para tener copia de seguridad y para compartir.
