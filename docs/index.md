## Cómo usar esta web

- Los bloques de código tienen un botón para **copiar**. Pega los comandos en la terminal.
- Donde el sistema operativo importa, verás pestañas **Windows / macOS / Linux**. Elige la tuya.
- Si algo falla, mira la última página de cada mini-curso (**Problemas habituales**) antes de preguntar.
- Las tareas, entregas y la información del módulo están en **Aules**, no aquí.
